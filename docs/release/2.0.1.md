**State (2026-10-27):** [GitHub stable release `v2.0.1`](https://github.com/DaniilSydorenko/haversine-geolocation/releases/tag/v2.0.1) was published on 2026-10-25 and the maintainer's npm staging succeeded. Independent [public npm registry and installed-consumer verification](https://github.com/DaniilSydorenko/haversine-geolocation/actions/runs/40428171115) passed on 2026-10-27 (12/12 Node/version matrix, SHA checks and npm signatures). Documentation and roadmap closeout remain under [#189](https://github.com/DaniilSydorenko/haversine-geolocation/issues/189). Do not repeat or republish the immutable `2.0.1` release.

## Version decision
The maintainer explicitly selected **`2.0.1` as the first stable V2 release**, skipping `2.0.0`. This is a permitted semantic version, even though `.1` conventionally denotes a patch to an existing stable release. **No stable `2.0.0` was ever published.** The previously published `2.0.0-alpha.1`, `2.0.0-beta.1` and `2.0.0-rc.1` remain immutable release history; no further prerelease is required.

## Stable V2 contracts
- New pure named `distance()` and generic single-pass `nearest()`; strict coordinate/unit/radius validation and full numeric precision with default mean Earth radius.
- Legacy V1-compatible default export during 2.x and explicit `./legacy`, plus isolated `./browser` geolocation adapter.
- Node-safe package root, dual ESM/CommonJS, TypeScript declaration exports, zero runtime dependencies, curated `dist/` tarball and UMD build.
- Keep V1→V2 intentional breaking changes explicit: legacy facade for compatibility, different spherical radius and rounding defaults for new APIs, input validation and restricted deep-import paths.
- Retain [accepted mathematical exact-pole fix #175](https://github.com/DaniilSydorenko/haversine-geolocation/pull/175) from public RC.1, plus [merged Cursor Pilot tests #178](https://github.com/DaniilSydorenko/haversine-geolocation/pull/178) for North/South Pole `nearest()` invariance. Pilot added tests only, no additional runtime changes after RC tag.
