# Haversine Geolocation 2.0.1 — First Stable V2 Release

Haversine Geolocation V2 brings a modern, typed API for spherical distance calculations and nearest-point searches while preserving a migration path for existing V1 consumers.

**Version note:** `2.0.1` is the **first stable V2** release. The stable `2.0.0` version was intentionally skipped; `2.0.0-alpha.1`, `2.0.0-beta.1` and `2.0.0-rc.1` remain available as immutable prereleases.

## What's new

- **Functional V2 API:** `distance(from, to, options?)` and `nearest(origin, candidates, options?)`.
- **Typed, validated coordinates and units:** coordinates use `{ latitude, longitude }`; distance units are `m`, `km` and `mi`. Invalid values raise explicit errors.
- **Precise spherical distance:** uses the mean Earth radius (6,371,008.8 m) by default, with configurable radius and no automatic presentation rounding.
- **Predictable nearest-point results:** a single-pass search returns `{ point, distance }` (or `undefined` for no candidates), preserving the original candidate object without mutation.
- **Package interoperability:** Node-safe root, ESM and CommonJS entrypoints, TypeScript declarations, isolated `./browser` and `./legacy` subpaths, and a browser UMD artifact; no runtime dependencies.
- **Pole edge-case fix:** exact zero distance for points at the same North or South Pole, independent of longitude, with regression coverage.

## Installation

```bash
npm install haversine-geolocation@2.0.1
```

Once npm's `latest` dist-tag points to `2.0.1`, the unversioned `npm install haversine-geolocation` command installs V2.

## New API example

```ts
import { distance, nearest } from 'haversine-geolocation';

const warsaw = { latitude: 52.2296756, longitude: 21.0122287 };
const oslo = { latitude: 59.9138688, longitude: 10.7522454 };

const kilometres = distance(warsaw, oslo); // km, full calculation precision
const closest = nearest(warsaw, [
  { id: 'oslo', ...oslo },
  { id: 'near-warsaw', latitude: 52.23, longitude: 21.01 },
]);
// closest?.point is the original selected object
```

## Upgrading from V1

This is a major-version upgrade. The legacy default facade remains available during the 2.x migration line:

```ts
import HaversineGeolocation from 'haversine-geolocation';
// Historical V1-style usage remains available:
HaversineGeolocation.getDistanceBetween(pointA, pointB, 'km');
```

For new code, use the named V2 functions. V2 validates coordinates and units more strictly, uses a different default spherical radius, returns unrounded numeric distances, and exposes supported package subpaths rather than historical deep imports. The legacy default facade retains the historical V1 calculation conventions.

**Migration details:** [V1 → V2 guide](https://github.com/DaniilSydorenko/haversine-geolocation/blob/master/docs/migration/v1-to-v2.md) · [API reference](https://github.com/DaniilSydorenko/haversine-geolocation/blob/master/docs/api-reference.md) · [Compatibility matrix](https://github.com/DaniilSydorenko/haversine-geolocation/blob/master/docs/compatibility.md).
