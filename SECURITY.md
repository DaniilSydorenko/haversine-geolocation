# Security Policy

## Supported versions

Security fixes are evaluated against the latest published version of `haversine-geolocation`.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting when it is available for this repository. If that channel is unavailable, contact the repository owner through the contact information on the GitHub profile and include:

- a clear description of the issue;
- the affected version or commit;
- reproduction steps or a minimal proof of concept;
- the potential impact.

Please avoid including real credentials, personal data, or other sensitive information in reports.

## Response expectations

Reports will be reviewed on a best-effort basis. Confirmed issues will be tracked privately until a safe fix and disclosure path are available.

## Scope

Security reports should concern the library, its packaging, release process, or repository automation. General geolocation privacy questions that do not identify a vulnerability are better suited to normal repository discussions or issues.
